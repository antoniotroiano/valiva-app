# Entwurfsskizzen der Oberfläche (intern)

Statische HTML-Entwürfe, die der Autor vor dem Bauen jeder Seite freigegeben hat ("Ja, bauen"). Sie zeigen die Planung, nicht den heutigen Stand der App; maßgeblich ist die App selbst. Die Namen mit `-apNN` gehören zu Arbeitspaketen aus dem Review-Bericht (`concept/14-review-report-2026-11-22.md`). Alle Zahlen und Namen sind erfunden.

Zum Ansehen die Datei im Browser öffnen (`mockup.css` liegt daneben). Kommentare im Code der App verweisen auf einzelne Dateien, deshalb bleiben sie hier liegen.
